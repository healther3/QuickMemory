# 轻记（QuickMemory）隐私说明

更新日期：2026-10-07。本文描述当前开源桌面应用的数据处理方式，是商店发布准备稿；正式发布者应核对发布版本、联系方式和商店声明后再提交。

## 本地数据

轻记无需登录。题库、标签、文件夹、考试答案、评分结果、历史记录和模型设置存储在当前电脑的 SQLite 数据库中，不提供账号、云端数据库或自动云同步。AI 核对的结果本身不入库；用户采纳并保存的定义会成为题库内容。

便携版默认把数据库放在 EXE 同级的 `data/quickmemory.db`；商店安装版使用当前 Windows 用户的 `%LOCALAPPDATA%/Packages/<PackageFamilyName>/LocalState/data/quickmemory.db`。`<PackageFamilyName>` 是 Windows 根据安装包身份生成的包族名称。设置环境变量 `QUICKMEMORY_DB` 时，数据库改用该变量指定的路径。两种发行方式不会自动迁移彼此的数据。

模型 API 密钥保存在本地数据库中，目前是明文存储。设置界面不回显保存的密钥，普通设置查询只返回是否已配置。任何能够读取该数据库的人员或程序都可能取得密钥；请勿将数据库或完整数据目录公开分享。文件夹 JSON 导出包含题目、定义、参考说明和标签，不包含模型密钥或考试历史。

## 何时向模型服务发送内容

只有使用 AI 功能时，应用才会通过用户配置的接口地址调用模型服务：

- **测试连接**：发送测试提示、模型名称及鉴权所需的密钥，不发送整套题库。
- **AI 核对**：发送正在核对的术语、参考定义，以及填写的参考说明。
- **考试评分**：发送该题术语、参考定义、作答内容、允许的错误类型和评分指令；多个裁判会分别调用模型，文字合并会再发送裁判反馈等内容。已提交且尚未完成的评分可能在下次启动时恢复。

这些请求直接发往所配置的服务，没有轻记运营方的中转服务器。密钥用于接口鉴权。若用户配置的是本机模型接口，请求发往该本机地址；若配置的是外部服务，内容会离开当前电脑。服务提供商对请求的留存、使用和跨境处理取决于其自己的政策和用户与其的约定，轻记无法替其删除已接收的内容。

## 运行组件与诊断

应用不内置广告或使用行为分析，不主动向项目维护者上传题库、密钥或诊断日志，LiteLLM 遥测及远程模型价格表下载已关闭。启动日志保留在本机，用于排查运行问题。独立窗口使用 Microsoft WebView2；Windows、Microsoft Store 和 WebView2 自身的更新及诊断由微软组件和用户的系统设置控制。

应用的本地 HTTP 服务仅监听电脑的环回地址，供本机界面使用。导入文件由用户选择，导出文件保存到用户选择的位置。窗口缓存及未完成的输入可能保存在本机浏览器或 WebView2 的本地存储中。

## 管理、删除与联系

用户可以编辑或删除题目、文件夹和标签，也可以在设置中清除模型密钥。删除题目不会自动删除既有考试答案快照及评分历史。若要清除全部本地记录，应先退出应用，再处理上述实际数据目录以及窗口缓存；操作前可自行备份。卸载商店版本对应用数据的具体处理以 Windows 为准，便携版的数据文件不会因为删除 EXE 自动消失。

项目源码与问题反馈：[healther3/QuickMemory](https://github.com/healther3/QuickMemory)。请勿在公开 Issue 中提交 API 密钥、含隐私的题库、数据库或完整日志。正式商店发布前，发布者应在商店支持信息中提供用于非公开隐私请求的有效联系方式。
