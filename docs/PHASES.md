## 跨阶段约束

1. 本地、单用户、无登录、无部署、无云同步；运行时仅 LLM API 可访问外网。
2. 全部界面和 LLM 反馈用简体中文；用户输入与技术术语可保留原文。
3. 用户参考定义是唯一评分标准。模型额外知识仅进入独立的“不计分”提示，不影响分数或错误类型。
4. 数据库与 API 契约跨阶段保持一致；任何必要变更须明确说明原因和迁移影响。
5. 没有真实 API 密钥或外网实测时，必须区分“模拟验证通过”和“真实模型调用通过”，不得把未运行的验证写成成功。
6. 按用户后续授权连续完成阶段，最终说明已完成内容、验证结果和仍存在的限制。
